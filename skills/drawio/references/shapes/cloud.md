クラウドサービス図形(高頻度)
=========================

概要
-------------------------

このファイルは、クラウドサービス図形のうち利用頻度が高いものをまとめています。

AWS図形(mxAWS4.js)
-------------------------

`mxgraph.aws4.*`名前空間で定義されるAWSサービス図形です。

```xml
<mxCell value="EC2" style="shape=mxgraph.aws4.ec2;..." vertex="1" parent="1">
```

GCP図形(mxGCP2.js)
-------------------------

`mxgraph.gcp2.*`名前空間で定義されるGCPサービス図形です。

```xml
<mxCell value="Compute Engine" style="shape=mxgraph.gcp2.compute_engine;..." vertex="1" parent="1">
```

Azure図形
-------------------------

Azure専用図形セットも利用可能です。

Kubernetes図形(mxKubernetes.js)
-------------------------

`mxgraph.kubernetes.*`名前空間で定義されるKubernetes図形です。

```xml
<mxCell value="Pod" style="shape=mxgraph.kubernetes.pod;..." vertex="1" parent="1">
```
