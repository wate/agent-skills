スケッチモード
=========================

概要
-------------------------

D2は手書き風の美しい図表をレンダリングできます。

有効化方法
-------------------------

### Terrastruct(Webサービス)

Hand-drawnモードを有効化します。

### D2 CLI

`--sketch`フラグを使用します。

```bash
d2 --sketch input.d2 output.svg
```

### Playground

[https://play.d2lang.com](https://play.d2lang.com)でsketchオプションを有効化します。

特徴
-------------------------

- すべてのシェイプが手書き風に変換
- コネクションも手書き風の線に変換
- テーマと組み合わせて使用可能
- すべてのレイアウトエンジンで動作

使用例
-------------------------

```d2
# 通常のD2コードをそのまま記述
winter -> summer
summer -> trees
winter -> snow
trees -> sun

# CLI実行時に --sketch フラグを追加するだけ
```

```bash
d2 --sketch diagram.d2 output.svg
```

他の機能との併用
-------------------------

### テーマとの組み合わせ

```bash
d2 --sketch --theme 101 diagram.d2
```

### レイアウトエンジンとの組み合わせ

```bash
d2 --sketch --layout=elk diagram.d2
```

参考資料
-------------------------

詳細な解説は[公式ブログ記事](https://d2lang.com/blog/hand-drawn-diagrams/)を参照してください。

ベストプラクティス
-------------------------

- プレゼンテーション資料に最適
- 堅苦しくない雰囲気を演出
- ラフスケッチ的な図表に
- 正式なドキュメントには通常モードを推奨
- 技術的な精密さより視覚的な親しみやすさを優先する場合に使用
