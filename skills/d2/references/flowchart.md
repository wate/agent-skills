システムフローチャート(D2形式)
==============================

概要
-------------------------

D2言語を使ったシステムフローチャートの生成手順を提供します。
システム仕様やアルゴリズムから処理フローを可視化します。

適用場面
-------------------------

- システム処理フロー、API連携、データ処理を可視化するとき。
- アルゴリズムやプログラムロジックを技術者向けに示すとき。

非適用場面
-------------------------

- 業務プロセスを担当者単位で示す場合(`activity.md`のアクティビティ図を参照)。
- コンポーネント間の時系列のやり取りを示す場合(`sequence-diagrams.md`を参照)。

生成手順
-------------------------

### 1. 処理フロー要素の特定

- 処理ステップ(開始・終了、関数呼び出し、計算)を特定します
- 判断ポイント(if-else、switch、三項演算子)を特定します
- データ入出力(API入力、ユーザー入力、ファイル読み込み)を特定します
- 制御フロー要素(例外処理、ループ、外部呼び出し)を特定します

### 2. D2文法による構造化表現

ノード形状は目的に応じて選択します。

| 要素         | shape                               |
| ------------ | ----------------------------------- |
| 処理         | `rectangle`                         |
| 判断         | `diamond`                           |
| 開始・終了   | `oval`                              |
| データ入出力 | `parallelogram`                     |
| データ格納   | `cylinder`                          |
| サブプロセス | `rectangle` + `style.double-border` |
| 例外処理     | `hexagon`                           |

- エッジの方向と種類を明確に表現します
- 条件分岐の複数出口と、ループの終了条件を明確にします
- グループ化とラベル付けで論理構造を示します

### 3. 技術仕様書向けの最適化

- 論理的に上から下、左から右へ流れる構成にします
- 技術的な抽象化レベルを揃えます
- 各要素へ意味のある識別子を付与します

### 4. 出力

- 出力先は`docs/feature/{業務}/{プロセス}_flowchart.d2`を既定値とします
- 業務名とプロセス名は英語小文字のアンダースコア区切りにします
- 呼び出し元の指示がある場合は、その出力先を優先します

出力サンプル
-------------------------

[システムフローチャートの記入例](../assets/flowchart_template.d2)

出力前に必ずサンプルを参照し、書式を一致させてください。

図種固有の制約・禁止事項
-------------------------

- D2コード以外の説明文を出力に含めません
- フローの論理的順序を無視した図を作成しません
- 判断条件が複雑な場合は、条件を単純化します
