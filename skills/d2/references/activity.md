アクティビティ図(D2形式)
=========================

概要
-------------------------

D2言語を使ったアクティビティ図の生成手順を提供します。
業務プロセスをスイムレーンで整理し、責任範囲を明確にして可視化します。

適用場面
-------------------------

- 業務プロセスを担当者単位で可視化するとき。
- 分岐条件と並行処理を整理するとき。

非適用場面
-------------------------

- 担当者を持たないシステム処理の流れを示す場合(`flowchart.md`を参照)。
- コンポーネント間の時系列のやり取りを示す場合(`sequence-diagrams.md`を参照)。

生成手順
-------------------------

### 1. 業務プロセスの分析と要素特定

- アクティビティ(処理ステップ)と制御フローを把握します
- 決定ノードとフォーク・ジョインノードを特定します
- 責任範囲とスイムレーン構造を設計します

### 2. D2言語による図表現の設計

- 制御フローは上から下、左から右へ配置します
- グループ化とスイムレーンで責任範囲を明確にします
- 一貫したインデントと意味のある識別子を付けます

### 3. shape定義

| 要素               | shape                            |
| ------------------ | -------------------------------- |
| アクティビティ     | `rectangle`                      |
| 開始               | `circle`(塗りつぶし)             |
| 終了               | `circle` + `style.double-border` |
| 決定               | `diamond`                        |
| マージ             | `diamond`                        |
| フォーク・ジョイン | `rectangle` + 横線               |
| オブジェクト       | `rectangle` + `border-radius`    |

### 4. 出力

- 出力先は`docs/workflow/{業務プロセス名}_activity.d2`を既定値とします
- 日本語の業務名は英語小文字のアンダースコア区切りに変換します
- 呼び出し元の指示がある場合は、その出力先を優先します

出力サンプル
-------------------------

[アクティビティ図の記入例](../assets/activity_template.d2)

出力前に必ずサンプルを参照し、書式を一致させてください。

図種固有の制約・禁止事項
-------------------------

- スイムレーン使用時は責任範囲を曖昧にしません
- フォークとジョインを対応させます
- 入力に存在しない要素を追加しません
