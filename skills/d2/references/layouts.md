レイアウトエンジン
=========================

レイアウトエンジンの選択
-------------------------

3つのレイアウトエンジンが利用可能です。

### dagre(デフォルト)

- 階層型レイアウト
- Graphviz DOTアルゴリズムベース
- 高速動作
- 方向性のあるグラフ向き

### ELK

- 成熟したレイアウトエンジン
- アカデミックな研究チームによる継続的メンテナンス
- より複雑なレイアウトに対応

### TALA

- D2 v0.9.0以降に本体へ同梱(D2と同じMPL-2.0で利用可能)
- ソフトウェアアーキテクチャ図を想定して設計された直交(orthogonal)レイアウト
- ホワイトボードに近い配置になり、階層型エンジンが苦手とする非階層の構成図に強い
- 対称性、コンテナの扱い、ラベル位置の自動調整を考慮する
- `top`/`left`による座標固定、コンテナ単位の`direction`指定に対応する

#### TALAのトレードオフ

- アルゴリズムにランダム性がある(既定では3つのシードを試し、最も良い結果を採用する)。ノードやラベルをひとつ追加するだけで配置が大きく変わることがある
- 長く流れるDAGの表現はdagre/ELKの方が安定する
- 図が大きくなるほど実行時間が非線形に増える
- 再現性を確保したい場合はシードを指定する(`d2 --layout tala --tala-seeds 44 input.d2 output.svg`)

**注記**: 導入済みバージョンで利用可能かどうかは`d2 layout`で確認できます。
`tala (bundled)`と表示されれば追加インストールは不要です。
旧バージョン(v0.9.0未満)ではTALAは別途インストールするクローズドソースのレイアウトエンジンでした。

レイアウトエンジンの指定
-------------------------

```d2
vars: {
    d2-config: {
        layout-engine: tala  # elk, dagre, tala
    }
}
```

または、CLIフラグまたは環境変数で指定:

```bash
# フラグ
d2 --layout=elk input.d2

# 環境変数
D2_LAYOUT=elk d2 input.d2
```

レイアウトエンジン固有の機能
-------------------------

### near(オブジェクトへの配置)

- TALA: オブジェクト指定可能
- dagre/ELK: 定数のみ(top-left等)

### width/heightのコンテナへの適用

- ELK: 対応
- TALA: 未対応(将来対応予定)
- dagre: 非対応

### top/leftによる位置固定

- TALA: 対応
- その他: 非対応

### 祖先-子孫間の接続

- dagre: 非対応
- ELK/TALA: 対応

### コンテナごとのdirection指定

- TALA: 対応
- dagre/ELK: 非対応(グローバル指定のみ)

direction指定
-------------------------

### グローバル方向

```d2
direction: right  # up, down, right, left
```

### コンテナごとの方向(TALAのみ)

```d2
vars: {
  d2-config: {
    layout-engine: tala
  }
}

direction: down
a -> b -> c

b: {
  direction: right
  1 -> 2 -> 3
}

a: {
  direction: left
  foo -> bar
}
```

使用上の注意
-------------------------

- まずdagre(デフォルト)で描画し、レイアウトに不満がある場合にELKまたはTALAを試す
- 複雑な階層構造が必要な場合はELKを試す
- 非階層のアーキテクチャ図や、座標・方向を意図どおりに制御したい場合はTALAを試す
- 長く流れるDAGはdagre/ELKの方が安定する
- 配置が気に入らない場合は`--tala-seeds`で別のシードを試す
- dagre/ELKではグローバル方向指定のみ対応(コンテナごとの指定はTALAのみ)
