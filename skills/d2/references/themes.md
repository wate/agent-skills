テーマ
=========================

テーマの指定
-------------------------

### CLIフラグ

```bash
d2 -t 101 input.d2
d2 --theme 101 input.d2
```

### 環境変数

```bash
D2_THEME=101 d2 input.d2
```

### 利用可能なテーマ一覧

```bash
d2 themes
```

ダークテーマ
-------------------------

### ダークテーマの指定

ユーザーのシステム設定がダークモードの場合に適用されるテーマを設定できます。

```bash
d2 --dark-theme 200 input.d2
```

または環境変数:

```bash
D2_DARK_THEME=200 d2 input.d2
```

### 注意事項

- デフォルトではダークテーマ未設定
- ライト/ダークテーマのIDは別カタログで管理されているが、相互利用も可能

特殊テーマ
-------------------------

### Terminal(300番)

特定のデフォルト設定が適用されます

- ラベルをすべて大文字化
- border-radius: 0
- フォントをmonospaceに変更
- コンテナの`fill-pattern: dots`
- 最外コンテナに`double-border: true`

テーマのカスタマイズ
-------------------------

### カラーコードのオーバーライド

```d2
vars: {
    d2-config: {
        theme-overrides: {
            B1: "#2E7D32"
            B2: "#66BB6A"
            AA2: "#0D47A1"
            AB4: "#F44336"
        }
    }
}
```

### カラーコードの一覧

公式ドキュメントに全カラーコード図あり(現在使われていないコードも将来の機能で使われる可能性があります)。

テーマの適用範囲
-------------------------

- 通常のシェイプ
- sql_tableやclass等の特殊シェイプ
- シーケンス図
- グリッド図

推奨事項
-------------------------

- プロダクション向けには統一感のある組み込みテーマを使用
- Terminal等の特殊テーマは用途に応じて活用
- カスタマイズは必要最小限のカラーコードのみに限定
- ダークテーマを設定してアクセシビリティを向上
