セキュリティポリシーの収集と監査
================================

セキュリティポリシー専用の内容をまとめます。
テンプレート変数と、基準の種類ごとの根拠の探し方を扱います。

テンプレート変数
-------------------------

テンプレートは基準値を変数として持ちます。
生成時はプロファイルと既存文書から値を決め、変数を残したまま出力しません。

| 変数                             | 意味                                   | 目安                           |
| -------------------------------- | -------------------------------------- | ------------------------------ |
| `{プロジェクト名}`               | ポリシーの対象プロジェクト名           | プロジェクトブリーフの名称     |
| `{対象システム}`                 | ポリシーが対象とするシステム           | プロジェクトブリーフの概要     |
| `{対象環境}`                     | 対象とする実行環境                     | インフラ設計書の環境           |
| `{対象者}`                       | ポリシーを適用する対象者               | プロジェクトブリーフの関係者   |
| `{Critical対応期限}`             | Criticalの対応を開始する期限           | 72時間                         |
| `{High対応期限}`                 | Highの対応を開始する期限               | 72時間                         |
| `{Medium対応期限}`               | Mediumの計画を定める期限               | 1週間                          |
| `{ログ保存期間}`                 | ログを保持する期間                     | 6ヶ月                          |
| `{第一報告期限}`                 | インシデントを第一報する期限           | 営業時間内                     |
| `{影響評価期限}`                 | 影響範囲と重要度を評価する期限         | 営業日1日                      |
| `{セキュリティ運用設計書}`       | セキュリティ運用を定めた設計書のパス   | 運用設計書の置き場所           |
| `{セキュリティガイドライン}`     | 安全な実装を書いたガイドラインのパス   | `docs/guideline/security/`配下 |
| `{依存関係の脆弱性管理のCI設定}` | 依存関係の脆弱性管理を行うCI設定のパス | CI設定ファイル                 |
| `{静的解析の設定}`               | 静的解析の設定のパス                   | 静的解析の設定ファイル         |

数値の目安は一般的な出発点です。
セキュリティの節は規模で落としません。基準値を、規模と扱うデータに合わせます。
既存文書やCI設定に値がある場合は、そちらを優先します。

根拠の収集
-------------------------

基準の種類ごとに、次の場所を探します。

### セキュアコーディングの基準

- 静的解析の設定とルールセット
- コーディング規約
- レビューの記録

### 依存関係セキュリティの基準

- 依存パッケージの脆弱性スキャンの設定
- CIの定期実行ジョブ
- EOLの確認記録

### データ保護の基準

- データベースの暗号化設定
- アクセス権限の定義
- バックアップの設定と復旧の記録

### ログ・監査の基準

- ログの出力設定
- ログの保存期間の設定
- 監査ログの改ざん防止の設定

### 設定管理の基準

- 変更管理の定義
- 設定ファイルのバージョン管理
- ロールバックの手順

### セキュリティ監査の基準

- 監査の計画と記録
- 監査項目の一覧

### インシデント対応の基準

- インシデント対応の定義
- 報告と影響評価の記録
- エスカレーションの区分

### 品質保証の基準

- セキュリティ設計書
- 対応記録
- 監査証跡
