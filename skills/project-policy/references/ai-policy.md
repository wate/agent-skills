AI利用ポリシーのテンプレート変数と根拠
======================================

このファイルは、開発時のAI利用ポリシーを生成・監査するときの参考情報です。
システム機能として組み込むAIの基準は、対象範囲を確認してから扱います。

テンプレート変数
-------------------------

| 変数                   | 意味                       | 目安                                       |
| ---------------------- | -------------------------- | ------------------------------------------ |
| `{禁止する入力情報}`   | AIへ入力してはならない情報 | 認証情報、個人情報、機密情報               |
| `{確認対象}`           | 人による確認が必要な生成物 | 成果に影響するコードや設計                 |
| `{利用するAIサービス}` | 開発で利用できるAIサービス | 提供元とデータの取扱条件を確認したサービス |

テンプレートに使う値は、プロジェクトの事実またはユーザーの判断から決めます。
値が決まらない場合は「要確認」とし、推測で補いません。

基準の根拠
-------------------------

| 基準の種類         | 主な確認先                                             |
| ------------------ | ------------------------------------------------------ |
| 入力情報           | データ分類、AIサービスのデータ取扱条件、利用者向け案内 |
| 生成物の確認       | コードレビュー規則、テスト設定                         |
| 利用するAIサービス | サービス一覧、契約条件、利用ルール                     |

プロジェクトに組み込んだAIの応答・判断基準は、AIポリシーの対象として独自の方針判断が必要かを確認します。
プロンプトインジェクションなど、脅威への対策はセキュリティポリシーの根拠を参照します。
同じ基準を複数のポリシーへ重複して記載しません。
