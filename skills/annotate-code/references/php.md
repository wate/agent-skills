PHPのアノテーション
=========================

書式
-------------------------

- PHPDoc形式で書き、`@param`・`@return`・`@throws`・`@var`のタグを使う
- 配列は要素の型まで書く(`array<string, mixed>`、`list<int>`、`array{id: int, name: string}`)
- nullを許す型は`string|null`のようにUnion型で書く
- 型が特定できない場合は`mixed`を使う
- コンストラクタの引数で宣言したプロパティ(コンストラクタのプロモーション)は、コンストラクタのDocコメントの`@param`で説明する
- PHP 8の属性(`#[...]`)はコードの一部のため、追加・変更しない

ジェネリクス
-------------------------

- ジェネリクスのクラスを継承する場合は`@extends`、インターフェースを実装する場合は`@implements`を、クラスのDocコメントに書く
- ジェネリクスのトレイトを使う場合は、`@use`をクラスの中の`use`文の直前に書く
- 親が`@template`で宣言した型引数は、すべて指定する。数が合わないと、PHPStanがエラーにする
- 型引数を持つクラスを新しく書く場合は、`@template`で型引数を宣言する

親のメソッドの上書き
-------------------------

phpDocumentorの規則では、上書きしたメソッドに説明がなければ、親の説明が自動で引き継がれます。
Docコメントを必須にするリンターがある場合は、親と同じ説明でよいメソッドに`@inheritDoc`だけのDocコメントを書き、書き忘れでないことを示します。
親と振る舞いが違う場合は、違いを説明に書き、親と異なる`@param`・`@return`を書き直します。

テンプレートファイル
-------------------------

テンプレート(ビュー)のファイルにはクラスや関数がないため、ファイルの先頭のDocコメントに、テンプレートで使う変数を`@var`で書きます。
`$this`にはビューのクラスを書き、コントローラーから渡される変数には、渡している箇所を読んで確かめた型を書きます。
CakePHPのbakeが生成するテンプレートも、この形で書かれています。

```php
<?php
/**
 * @var \App\View\AppView $this
 * @var iterable<\App\Model\Entity\User> $users
 */
?>
```

フレームワークのマジックメソッドとプロパティ
--------------------------------------------

フレームワークが`__get()`や`__call()`で提供するプロパティとメソッドは、クラスのDocコメントに`@property`・`@method`で書きます。
静的解析が実在しないと判定するメンバーは、書く前にフレームワークのソースか生成コードで実在を確かめます。
フレームワークのコード生成ツールが書くDocコメント(CakePHPのbakeが書く`@property`など)は、生成された書式に合わせます。

差分の機械的な確認
-------------------------

`php -w`は、コメントと余分な空白を除いたコードを出力します。
作業前の複製と今のファイルで結果が一致すれば、変わったのはコメントと空白だけです。
`php -w`はPHP本体だけで動くため、静的解析のツールを入れていない環境でも使えます。

```bash
diff <(php -w 作業前の複製.php) <(php -w 対象.php) && echo "コメント以外の変更なし"
```

静的解析
-------------------------

- PHPStan・PsalmはPHPDocの型を読むため、コメントの型の誤りがエラーとして出る
- PHP_CodeSnifferは、規約に設定されていればDocコメントの有無と書式を検査する

見本
-------------------------

```php
/**
 * ユーザーの一覧画面を表示する
 *
 * 有効なユーザーだけを、ページ単位で表示します。
 *
 * @property \App\Model\Table\UsersTable $Users
 */
class UsersController extends AppController
{
    /**
     * 一覧の1ページあたりの件数と並び順
     *
     * @var array<string, mixed>
     */
    protected array $paginate = [
        'limit' => 25,
        'order' => ['Users.name' => 'asc'],
    ];

    /**
     * ユーザーの一覧を表示する
     *
     * @param string|null $status 絞り込むステータス。nullの場合は全件を表示する
     * @return void
     * @throws \Cake\Http\Exception\NotFoundException 存在しないページ番号を指定した場合
     */
    public function index(?string $status = null): void
    {
        // 処理
    }
}
```
