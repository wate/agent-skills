作業プラン・引き継ぎ資料の読み取り
==================================

対象
-------------------------

作業プランと引き継ぎ資料は、どちらも作業の記録です。
見出しの名前が違うため、次の対応で読み替えます。

| 出力の項目 | 作業プラン             | 引き継ぎ資料           |
| ---------- | ---------------------- | ---------------------- |
| 目的       | 作業指示書情報         | 目的                   |
| 現在地     | 作業一覧のチェック状態 | タスク一覧の状態と進捗 |
| 決定       | 設計判断ログ           | 決定事項               |
| 課題       | 課題・リスク           | 課題とリスク、未決事項 |
| 次         | 未チェックの作業       | 未完了のタスク         |
| 成果物     | 成果物                 | 成果物                 |

拾う事実
-------------------------

- 目的: 何のために始めた作業か。
- 現在地: 完了した作業と、進行中の作業。作業番号ではなく、終えた内容で書きます。
- 決定: 決めた内容と、その理由。
- 課題: 未解決の問題、リスク、未決事項。
- 次の作業: 未完了のタスクと、次に着手する順序。
- 成果物: 作成または変更したファイル。

拾わないもの
-------------------------

- 完了条件の細目や受け入れ基準の全文。
- 作業履歴の全行。経緯は決定と課題に絞ります。
- 各タスクの手順の詳細。
- 解決済みの課題の詳しい経緯。
